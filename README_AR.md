# دليل تشغيل البورتفوليو — النسخة الجديدة

تم تجديد الهوية البصرية لبورتفوليو **Farid** بألوان هادئة ومتناسقة، مع تحسين تنسيق الأقسام والبطاقات والأزرار ونموذج التواصل، وتوفير وضع فاتح ووضع داكن متكاملين.

## معاينة فورية

افتح **`Portfolio_Preview.html`** بنقرتين داخل المتصفح. هذه نسخة مجمّعة مستقلة للمعاينة؛ لا تحتاج إلى تثبيت Node أو تشغيل خادم، والصور والخطوط مضمّنة فيها.

يمكن مشاهدة التصميم والتنقل بين أقسامه دون إنترنت. إرسال نموذج التواصل وفتح روابط المواقع والحسابات الخارجية يحتاجان إلى اتصال بالإنترنت. هذه المعاينة تمثل النسخة المرفقة؛ بعد تعديل المصدر، نفّذ `npm run build:preview` لتحديثها.

## الألوان الجديدة

الهوية تعتمد على **العاجي الدافئ والجرافيت مع لمسات نحاسية**. العناوين والنصوص والحدود والأزرار وحقول الإدخال تستخدم نظام ألوان موحّدًا.

| الاستخدام | الوضع الفاتح | الوضع الداكن |
| --- | --- | --- |
| الخلفية الرئيسية | `#F6F3ED` | `#191D1B` |
| أسطح البطاقات | `#FFFDFA` | `#222725` |
| النص الأساسي | `#252925` | `#F1EEE7` |
| اللون المميز | `#A5442C` | `#E5AB89` |

لتعديل الألوان لاحقًا، افتح **`src/style.css`**. مجموعة `:root` تخص الوضع الفاتح، ومجموعة `:root.dark` تخص الوضع الداكن. بعد التعديل، نفّذ `npm run build:preview` لتظهر الألوان الجديدة في نسخة الإنتاج والمعاينة المستقلة معًا.

## ما الذي تم الاحتفاظ به؟

- هوية Farid ومحتوى الخدمات والمهارات والخبرات والتعليم والمشروعات.
- الصورة الشخصية وملفات الشعار وصور المشروعات الأصلية.
- روابط الحسابات الاجتماعية وإعدادات خدمة التواصل الأصلية.
- بقي ملف `Counter.vue` غير مستخدم في الصفحة؛ لم تُضف أرقامه إلى المحتوى المعروض.

## محتويات الحزمة

| الملف أو المجلد | وظيفته |
| --- | --- |
| `src/` | ملفات Vue والتصميم والمحتوى القابل للتعديل |
| `public/` | ملفات عامة إضافية، مثل ملف السيرة الذاتية عند إضافته |
| `package.json` و`package-lock.json` | إعدادات التشغيل والاعتماديات |
| `dist/` | نسخة الإنتاج المبنية، المناسبة للرفع إلى استضافة مواقع ثابتة |
| `Portfolio_Preview.html` | معاينة مستقلة تُفتح مباشرة داخل المتصفح |
| `src/config.js` | إعداد رابط السيرة الذاتية وخدمة EmailJS |

**يُفضّل استخدام المشروع كاملًا** بدل استبدال مجلد `src` وحده داخل المشروع القديم. النسخة الجديدة تستخدم خطوطًا وأيقونات محلية، ولم تعد تحتاج إلى Tailwind أو AOS أو Iconify أو Countup لتشغيل الواجهة. ملف الاعتماديات الجديد مرفق مع المشروع.

## التشغيل والتعديل

تحتاج إلى **Node.js إصدار 22.18 أو أحدث**. افتح Terminal داخل المجلد الذي يحتوي على `package.json`، ثم نفّذ:

```bash
npm install
npm run dev
```

تثبيت الاعتماديات في المرة الأولى يحتاج إلى إنترنت. افتح الرابط الذي يظهر في Terminal لمعاينة الموقع أثناء التعديل.

بعد انتهاء التعديلات، أنشئ نسخة الإنتاج:

```bash
npm run build
```

هذا الأمر يحدّث مجلد `dist/` فقط. لتحديث نسخة الإنتاج **وملف المعاينة المستقلة** بعد أي تعديل، استخدم بدلًا منه:

```bash
npm run build:preview
```

سيعيد الأمر بناء `dist/` ويولّد `Portfolio_Preview.html` من النسخة المحدّثة. ولمعاينة نسخة الإنتاج محليًا:

```bash
npm run preview
```

عند الرفع إلى استضافة ثابتة، استخدم **محتويات `dist/` بالكامل**. للفتح المباشر بنقرتين استخدم `Portfolio_Preview.html`؛ نسخة `dist/` مصممة للعمل عبر خادم أو استضافة.

## إضافة السيرة الذاتية PDF

الأرشيف الأصلي كان يحتوي على `src` فقط، ولم يتضمن ملف السيرة الذاتية. لذلك بقي `resumeUrl` فارغًا، ولم يُنشأ ملف CV بديل أو رابط تنزيل وهمي.

1. ضع ملف السيرة الذاتية الحقيقي في:

   ```text
   public/cv/Farid_Fayez_CV.pdf
   ```

2. افتح `src/config.js` وعدّل قيمة `resumeUrl` فقط إلى:

   ```js
   resumeUrl: 'cv/Farid_Fayez_CV.pdf',
   ```

3. نفّذ `npm run build` ثم ارفع نسخة `dist/` المحدّثة. سيظهر رابط السيرة الذاتية في الموقع المبني بعد تفعيل الإعداد.

## نموذج التواصل

تم الاحتفاظ بإعدادات **EmailJS** الأصلية داخل `src/config.js`، مع تحسين التحقق من البريد الإلكتروني وحالات الإرسال والنجاح والخطأ. لا تظهر رسالة نجاح إلا بعد استجابة الخدمة بنجاح.

**لم يتم إرسال رسائل فعلية لاختبار التسليم.** قبل استخدام الموقع لاستقبال رسائل الزوار، تحقّق من حساب EmailJS والخدمة والقالب وإعدادات النطاقات المسموح بها. قد يحتاج عنوان الاستضافة الجديد إلى السماح به في الحساب. فتح المعاينة من ملف محلي قد لا يكون مسموحًا لدى الخدمة، حتى مع وجود إنترنت.

## روابط المشروعات

المصدر الأصلي يتضمن رابطًا خارجيًا محددًا لمشروع **Eripsaleen Choir**. المشروعات الثلاثة الأخرى كانت قيمة `website` فيها `/`، وتم الاحتفاظ بهذه القيم في البيانات مع عرض إجراء يوجّه إلى قسم التواصل بدل فتح رابط مشروع غير محدد.

عندما تتوفر الروابط الصحيحة، افتح **`src/components/layout/Projects.vue`** واستبدل قيمة `website` لكل مشروع بعنوانه الكامل، ثم أعد بناء المشروع.
